## README.md 实验与验证记录

### 算法与数据流

输入图像按空间块分配到 8 个 NPU，每个 NPU 的本地存储为 32 KiB。
每块一次载入参考图和包含整个视差搜索范围的目标图，后续所有视差都在本地存储中计算：

1. 用 max/min/sub 求精确绝对差，差值不超过 62，单字节可表示。
2. 用双字节平面进行精确 16 位水平和垂直求和，最大 SAD 为 `62*15*15=13950`。
3. 用 16 位减法符号掩码及按位选择更新最小代价与视差；代价相同保留较小的视差。
4. 仅传回最优代价和视差，分别为 uint16 / uint8，共 3 字节/像素。

640×400、D64 的完整 16 位代价体是 32,768,000 字节，本实验不传回它，
输出缓存为 768,000 字节。输入和输出都执行必要的缓存同步。
命令缓冲按块形状预生成并复用，初始化不计入逐帧耗时。

提供两种精确聚合方式：

- `direct`：每个方向逐项累计，默认 64×16 空间块。
- `tree`：按 `S3=1+1+1`、`S7=3+3+1`、`S15=7+7+1` 分阶段组合，
  每个方向从 14 次加法减为 6 次。默认块 64×10，额外中间缓存仍满足本地存储限制。

只定义完整窗口和全部视差都有效的区域：
`x ∈ [D-1+7, width-7)`、`y ∈ [7, height-7)`；其他输出为 0。
核心中视差 0 是合法候选，不能单凭非零值判断深度是否可信。

### 板端结果（2026-10-23）

CPU 1 GHz、TPU 700 MHz。真实输入使用旧 StereoBM 实验保存的 frame150 校正图，
可见墙面和家具，纹理较弱。每组两次预热、20 次测量，读取 PGM 和初始化不计入计时。

| 输入 / 聚合 | TPU 调用总耗时，含上传与取回 | CPU 预滤波 | 两者合计 | TPU 调用所用 A53 线程 CPU 时间 | 同输入完整 all64 StereoBM |
| --- | --- | --- | --- | --- | --- |
| 320×200 / D32 / direct | 19.47 ms | 2.35 ms | 21.81 ms | 1.07 ms | 19.92 ms |
| 320×200 / D32 / tree | **14.86 ms** | 2.36 ms | **17.22 ms** | 1.19 ms | 19.79 ms |
| 640×400 / D64 / direct | 96.37 ms | 9.04 ms | 105.41 ms | 3.16 ms | 124.17 ms |
| 640×400 / D64 / tree | **84.26 ms** | 8.95 ms | **93.21 ms** | 3.59 ms | 124.78 ms |

最后一列是完整 StereoBM，包含预滤波、唯一性检查、亚像素插值及过滤；
TPU 路径目前只有预滤波 + SAD/WTA，功能范围不同。不能把两列的比值当作
完整算法的已验证加速比，也不能将 `1000/93.21` 当作实时发布帧率。

640 tree 的执行/等待阶段约 82–83 ms，CPU 在等待期间大部分时间可运行其他任务。
目前最大的价值是释放 A53；这一版核心本身仍超过 50 ms，尚不满足 640×400 / 20 Hz。
校正、相机采集和 micro-ROS 未包含在上述结果内。

### 正确性与质量边界

- 每次调用都与独立的 CPU `absdiff + boxFilter + WTA` 参考实现逐像素比较
  最小 uint16 代价和 uint8 视差，包含输出边界；发现任何差异立即失败。
- 最终六组 CSV 共 102 次调用（含预热）全部通过；另测了 97×57 / D7 的奇数尺寸、
  尾块、随机图、遮挡、平坦图，以及最大代价 13950 的极端输入。
- 已知整数位移的随机纹理平面在全部被测调用中满足至少 99% 的正确视差比例。
  平坦图验证并列最小值规则；连续随机帧验证输入/输出缓存更新。
- 真实 frame150 上，CPU all64 判为有效的 359 / 567 个像素，TPU 整数 WTA
  均在其亚像素视差的 ±1 像素内。这是很小的有效子集，不构成完整质量验证。

**当前结果不能直接作为正式深度图输出。** 例如 640 frame150 的 217318 个核心像素中，
WTA 给出 208109 个正视差，而完整 BM 只保留 567 个有效像素。
缺少唯一性检查等处理时，大量墙面噪声会被错误地当成距离。

接入正式模式前仍需补齐：

1. 保留最佳视差邻域代价，恢复兼容的亚像素插值。
2. 唯一性、纹理、左右一致性和散斑过滤；对现有 mask 与毫米转换进行回归。
3. 测量上述处理加入后的总耗时，并在真实采集、校正、ROS 发送同时运行时复测。

现有原型未完成这些工作，因此没有发布 TPU 深度模式的实测 FPS。

# TideSense StereoBM board results

Dataset `dataset-20261012-084638`; A53 **1 GHz**, single thread, OpenCV 3.4.20 with NEON baseline, static GCC 11.3. No VIO, ROS, IVE or TPU. Each configuration processes all **885** pairs; means/p95 exclude the first **20** pairs. Input images are original 640x400 PGM images; fish-eye stereo rectification directly produces the requested output dimensions. Block size is 15.

## Interpretation

- 320x200 / 32 disparities fits the 50 ms budget in this compute benchmark; its p95 is 39.61 ms. Capture and publication costs still require live verification.
- 320x200 / 64 disparities averages 46.01 ms, but p95 is 51.06 ms; it has little margin for stable live 20 Hz.
- 640x400 / 64 disparities averages 250.84 ms, approximately 4 FPS. Ordinary StereoBM in this build cannot process full-resolution 20 Hz.
- Reading the two PGM files from SD takes approximately 54–55 ms per pair. This is replay I/O, not the cost of accessing a live captured pair.
- Coverage is low: many blank walls, close furniture/occlusion and noisy images produce invalid matches. A faster compute rate does not imply a complete or accurate depth map. No ground-truth depth was measured.

## Geometry check

Uses `cali/tidesense-stereo-yy-equi-20261011-231002/stereo-camchain.yaml`. Calibrated baseline 49.667 mm, rectified fx 139.987 / 279.974 px. The right-camera 180 degree rotation is folded into maps. To obtain positive disparities, physical right is the reference view. Depth images are therefore in the rectified physical right camera frame.

Host SIFT ratio-test checks on board-produced rectified samples: at 320x200, frames 400/600 yielded 88/62 positive-disparity correspondences with |dy|<1 px, median |dy| 0.280/0.223 px. At 640x400: 141/135 correspondences with |dy|<2 px, median |dy| 0.520/0.478 px. These sampled consistency checks are not ground-truth depth validation.

## Artifacts

- `results.json`: full summary, p95, valid coverage and processing budget fraction.
- `results/*.csv`: raw per-frame stage measurements.
- `results/*-depth.png`: 16-bit millimetres, 0 invalid.
- `results/*-disparity.bin`: signed little-endian int16 disparity with 4 fractional bits.
- `depth-preview.png`: illustrative images, fixed 0.25–5 m colour range; black invalid.
- `maps.json`: exact rectified projections and map-generation version.
- `RUN-INFO.json`, `board-run.log`: reproducibility and board clock checks.

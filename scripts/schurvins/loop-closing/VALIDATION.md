# SG2002 回环检测实测（2026-11-15）

已在 `192.168.123.99` 部署独立实验程序 `/mnt/data/schur-loop-closing`。
用户确认设备保持静止。本轮结论是：A53 上直接增加现有 ORB / DBoW2 检测后，
不能保证 20 FPS；当前小规模测试主要受计算和延迟峰值限制，没有耗尽内存。
检测结果尚不回灌 Schur EKF，不包含位姿图优化。

## 条件与实现范围

- SG2002 A53，Linux `5.10.4-tag--g576090c96ff9`；Linux MemTotal 157020 KiB。
- 两路 640×400 mono8，FSIN 约 20 Hz，SC7U22 约 199.55 Hz。
- 使用设备现有 equidistant 标定，原文件及原预装程序未覆盖。
- GCC 11.3.1，`-O3 -mcpu=cortex-a53`，七项 NEON 开关开启，静态 `none` 通信后端。
- `SCHUR_ROS=0`、`SCHUR_PREDICTION=0`；未使用 C906 / TPU 卸载。
- 上游双目示例的重叠参数：alpha/beta 0.8，忽略最近 20 个入库关键帧，
  bow_thresh 0.65，min_num_3d 10，orb_dist_thresh 48。
- 词袋 `voc_VI01_8X4.yml.gz`；2D 使用 OpenCV essential-matrix RANSAC，
  3D 使用 OpenGV。没有启用原 Ceres/SVO 的 extra_map_points 路径；
  检测使用现有 Schur 关键帧的地图点快照。
- 单个检测线程，最多一个待处理快照；上限 500 个入库关键帧，达到上限会结束实验。

## 静态实时结果

每组处理 600 帧；下表帧率剔除前 50 帧，按输入图像实际时间跨度计算。
所有组 tracking 和 IMU 覆盖计数均为 600，但这不表示定位精度通过验证。

|---|---|---:|---:|---:|---:|---:|---:|
| off-control | 关 | 16.98 | 85.9% | 16.8 MiB | 0 / 0 | 0 / 0 | 99 |
| on-upstream-1 | 开 | 17.81 | 54.8% | 27.4 MiB | 35 / 35 | 15 / 15 | 69 |
| on-upstream-3 | 开 | 11.46 | 87.2% | 39.9 MiB | 96 / 96 | 136 / 136 | 422 |

更早的关闭组分别为 19.85、19.88、16.65 FPS。实时顺序测试波动明显，
不能用某两组的差值给出普适的性能下降百分比。开启组已实际执行历史匹配和 2D 几何验证，
不是只加载词袋或打开一个未生效的开关。

`on-upstream-3` 的回环关键帧工作均值 / P95 / 最大值由原始 CSV 记录；
最大值约 1.89 秒。VIO 持续运行，但检测线程占用同一颗 A53，
会出现处理延迟和输入帧替换。该组收到 123 个回环输入，处理 96 个，
另有 27 个因待处理槽已满被跳过。

本轮静态测试所有组的最终 3D 确认闭环数均为 0。
不能由此评估移动后重访的检出率；静态零基线也不能充分验证 essential-matrix 路径。

## 相同录制输入的回放对照

输入来自已有完整记录 `install/readme-validation-20261019/vio-record`，180 组图像及同一份 IMU。
每次读取全部 180 帧，不采用实时相机丢帧策略。按 `processing_elapsed_s` 计算吞吐：
包含读图、VIO、快照及最后的后台排空，不含启动时词袋加载。

首个关闭组存在较多 CPU 外等待，后一个关闭组更快，因此保留两者，不选择性删除慢组。
两个开启组分别完成 6 / 3 次历史比较，均未达到后续 2D 验证所需的匹配数量。
真实执行 2D 几何验证的证据来自上面的实时组。
回放的图像时间戳间隔约为 9.53 FPS，这不是计算吞吐，不能用它报告程序帧率。

## 轨迹与验证限制

用户确认设备静止，但实时 `off-control` 和 `on-upstream-3` 的估计位置距各自起点
最大分别约 28.0 m 和 13.6 m；`on-upstream-1` 约 0.36 m。
关闭回环也存在漂移，本轮不能把它单独归因于回环。
当前数据只支持性能观测，不支持“定位正常”或“回环消漂已生效”的结论。

相同输入的两个关闭回放位置逐项一致；两个开启回放与关闭参考的最大位置差
分别约 2.4 cm、4.2 cm。未做带真值的精度评估，不宣称精度回归通过。

板端 `schurvins_loop_geometry_test` 在设备 equidistant 标定和 EuRoC radtan 标定下均通过：
80 个混合 ORB 像素 / VIO 视线的 2D 内点、40 个 3D 对齐内点，
2D 旋转矩阵误差分别约 `3.1e-6` / `9.4e-7`；还检查了退化输入处理。
合成 `--self-test` 的 6 帧跟踪和 IMU 融合通过，检测线程完成处理并正常退出。
这些测试不代替真实移动闭环验证。

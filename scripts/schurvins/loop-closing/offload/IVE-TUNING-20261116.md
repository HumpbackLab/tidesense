# IVE-ST 阈值校准（2026-11-16）

已将 IVE-ST 的默认 `SCHUR_ORB_IVE_QUALITY` 从 16 调整为 **3**，
使当前场景的最终 ORB 点数接近 FAST。数值范围仍为 1..255，越小通常保留越多点。
FAST 仍是普通入口的默认检测器；仅启用 IVE 时使用新阈值。
运行时不执行 FAST 来调节阈值，也没有增加在线双检测器开销。

## 同图校准

从设备实时双目 / IMU 输入录制了 40 帧，约 2 秒。
录制图像仅用于固定输入下比较点数，下面的实时 FPS 测试另行直接采集，没有读图回放。
选取 5 张左图扫描 24 个质量值，按最终 ORB 点数相对绝对误差选择全局值 3；
再用未参与选值的 4 张左图、4 张右图验证。
ORB 的层数、配额、边界、Harris 排序、方向与描述子步骤均保持原设置。

| 图像集 | FAST 平均最终点数 | IVE 阈值 16 | IVE 阈值 3 | 阈值 3 逐图相对绝对误差 |
| --- | ---: | ---: | ---: | ---: |
| 校准左图，5 张 | 329.2 | 173.0 | 331.6 | 3.40% |
| 留出左图，4 张 | 332.8 | 177.8 | 329.5 | 4.58% |
| 合计左图，9 张 | 330.8 | 175.1 | 330.7 | 3.93% |
| 留出右图，4 张 | 381.3 | 121.3 | 386.5 | 3.48% |

回环输入使用左相机快照，所以参数选择以左图为主。
平均点数接近不表示每张图都相同；逐图误差用于避免平均值正负抵消造成误解。

计数区分原始候选、边界过滤、初筛和最终点数。
**这里对齐的是最终用于 ORB 描述子的点数，候选点数、位置及金字塔层间分布仍然不同。**
例如 5 张校准左图的每层最终点数均值：

| 层 | FAST | IVE 阈值 3 |
| --- | ---: | ---: |
| 0 | 100.0 | 109.0 |
| 1 | 74.2 | 90.0 |
| 2 | 58.6 | 8.0 |
| 3 | 45.6 | 63.0 |
| 4 | 30.6 | 42.0 |
| 5 | 14.8 | 14.6 |
| 6 | 4.4 | 4.0 |
| 7 | 1.0 | 1.0 |

另试过分层阈值，以改善层间分布，但留出图上的总点数误差增大，最终保留全局阈值 3。
阈值适配当前场景，不能保证换场景后仍与 FAST 同点数，更不能保证回环检出率相同。

## 实时 VIO 对照

三组均为真实相机与 IMU，各处理 600 帧，exit=0、tracking=600、imu_fused=600。
不设置 `SCHUR_LOOP_REPLAY`。FPS 剔除前 50 帧，按已处理图像时间戳跨度计算，包含跳帧影响。
均使用 CPU NEON `cpu-batch` 匹配，关闭 ROS 和高频预测；本次未更换固件或接管 TPU。

| 路径 | 每次检测平均最终点数 | 实时稳态 FPS | 回环任务 | 几何验证次数 |
| --- | ---: | ---: | ---: | ---: |
| FAST | 323.4 | 13.96 | 58 | 351 |
| IVE 阈值 16 | 159.0 | 17.44 | 37 | 10 |
| IVE 阈值 3 | 329.3 | 13.64 | 52 | 171 |

阈值 3 的实际点数与 FAST 相差约 1.8%，整机 FPS 相近，本轮没有观察到 IVE 的整机加速。
阈值 16 的较高 FPS 同时伴随约一半点数与更少几何验证，不能视作同等工作量下的速度优势。
各轮是不同时间的实时输入，异步关键帧和候选数量也不同，不据此计算检测器的独立加速比。
本次最终确认回环均为 0，tracking 标志不代表精度或回环检出率验证。

## 部署与复现

新实验程序部署在 `/mnt/data/schur-ive-tune-20261116`，可直接运行：

```sh
cd /mnt/data/schur-ive-tune-20261116
./run-ive-tuned.sh --vio schurvins.yaml auto /tmp/poses.csv 600
# 需要重现旧阈值时：
SCHUR_ORB_IVE_QUALITY=16 ./run-ive-tuned.sh --vio schurvins.yaml auto /tmp/poses.csv 600
```

`run-ive-tuned.sh` 开启回环检测、IVE-ST、阈值 3 和 CPU NEON 匹配；环境变量可覆盖质量值。
默认关闭 ROS 和高频预测，以对应上述测试条件，也可通过环境变量覆盖。
普通程序入口仍默认关闭回环。原预装程序及标定未覆盖，实验结束后无遗留运行进程。

`profile_orb.py` 增加 `ORB_POINTS` 各层计数；同图扫描结果可用以下工具复算：

```sh
python3 scripts/schurvins/loop-closing/offload/tune_points.py \
  install/schur-ive-tune-20261116/coarse \
  install/schur-ive-tune-20261116/refine \
  install/schur-ive-tune-20261116/layers \
  --output /tmp/selection.json
```

主机数据位于 `install/schur-ive-tune-20261116/`：

- `record/`：本次实时输入快照；`coarse/`、`refine/`、`layers/`：固定图像扫描日志。
- `validation/`：留出图及分层试验日志；`points-summary.json`：逐图数量及汇总。
- `live/`、`live-summary.json`：三组实时逐帧、资源、回环日志及点数汇总。
- `BUILD-INFO.json`：阈值、源码与二进制 SHA-256、测量与部署版本说明。
- `device-final.txt`：部署二进制和原生产程序 / 标定哈希，以及未改变的 Linux boot ID。

计数插桩后的 FAST 描述子与原 OpenCV 在固定图像上逐字节一致；
最终默认阈值 3 与显式设置 3 的点数和描述子 checksum 一致。
质量值 0、256、4294967299 均正确拒绝；IVE 实际调用通过输出与 scratch 越界哨兵检查。
